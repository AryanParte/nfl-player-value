## What changed and why

The old solver adds a tiny prior precision to a large cross-product matrix.
Floating-point addition can lose the tiny quantity. When a QB effect, year effect
or team-wide shift has exactly the same observed consequence as another modeled
combination, the prior supplies essential information along that direction.
Losing it can make a mathematically positive system appear indefinite.

Plain QR avoids squaring the condition number but passes only 61/72 demanding
controls. The preferred solver first proves exact binary dependencies using
rational arithmetic. It integrates those proper-prior directions analytically,
then factors the remaining augmented rows by QR. Their uncertainty is restored,
including covariance with fixed context. Nothing is rounded into an alias;
near aliases stay in the model. No players are dropped or forced to have zero
value. Different precision blocks remain separate.

The original 80-/110-digit reference calculation passes 72/72 local cases for
exact-alias QR; archived normal equations pass 28/72 and plain QR passes 61/72.
The original exact-alias-only NFL fit completes in 4,938 evaluations / 41.2 seconds, but that
kernel later fails a portable near-alias residual check in GitHub Actions. Those
local passes were insufficient evidence of portability. All results are retained.

## Failure analysis and justified correction

Hosted CI exposed a residual quadratic error of 1.036e-9 against the unchanged
1e-9 limit. The means and variances passed. QR fits a nearby floating-point
problem; for nearly cancelling columns its transformed residual can differ from
the original-row objective. Raising the tolerance or skipping a Python version
would hide this issue.

Before changing the algorithm, commit `92d21ea` froze one correction and a fresh
synthetic response seed. The new candidate evaluates the original sparse-row
penalized residual with compensated products and summation, including game effects.
It preserves the same likelihood, priors and contrasts in exact arithmetic. No
Decimal oracle answer enters the fitted estimates. Its 72 regression cases and 72
fresh-response cases all pass; the worst residual error is 1.92e-14. This is
arithmetic evidence, not football calibration. All 85 declared archived coordinate
checks also pass, including the raw-row/reordered failing-point comparisons.
