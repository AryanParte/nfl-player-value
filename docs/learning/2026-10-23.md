## Statistical concepts

**Prediction is not attribution.** A model can predict better by knowing that a
receiving target was recorded. That does not show it has learned the receiver's
individual contribution. The role-only ablation has the same recorded role
information without actor identities, making this distinction measurable.
Target availability is realized information: sacks and throwaways affect it.
Conditioning on it can absorb value the quarterback created. This diagnostic
adjustment must not silently become the final CAVAA hardship adjustment.

**Shrinkage is an assumption, not new evidence.** Ridge minimizes squared error
plus squared-coefficient penalties. It pulls weakly supported coefficients toward
a common origin, similar to a fixed Gaussian-prior estimate. The experiment selects
penalty strength using validation games; it does not estimate a full Bayesian
hierarchy or player posterior intervals. The origin is not the approved first-unit
positional average. No benchmark contrast is computed in this unit.

If a quarterback and receiver always appear together, the data may identify only
their combined association. A unique ridge solution still splits that association
according to the penalty. The code flags identical actor columns and measures
actor/team coappearance. A synthetic crossed design recovers known effects; a
separate perfectly paired design illustrates the identification failure.

**Keep validation and test separate.** Fit on 2025 Weeks 1–10, select the actor
penalty on Weeks 11–14, refit through Week 14, then evaluate Weeks 15–18. Apply the
same frozen model to the available 2026 data as a transfer test. Penalty 100 has
slightly better final historical error than the selected 1000, but switching now
would tune on the test. The selected model stays unchanged. These test results are
now observed and cannot be presented as untouched tests for future revisions.

**Account for every outcome once.** The sum of context, offense/defense team,
shared role terms, actor terms and residual reconstructs one observed EPA per play.
Scrambles do not receive both dropback and carry effects. Unresolved actors leave
outcome rows intact with shared/residual components. None of these components is
an independently established causal share of the play.

## Measured results

Implementation `a595912cf16716dff479d6e3d63c8d8df4452b9b` generated report
`1fd9e2479c71ff06590a96e7b512fb291f80ad35bc10867d81814af7452660de`.
Inputs are the October 22 offensive artifacts, with full transitive raw provenance.
No fresh source download was necessary. The 2025 split has 149 training, 59
validation and 64 test games. The final refit uses 25,163 plays. There are 7,650
historical test plays and 11,441 transfer plays from 93 completed 2026 games.

| Model | 2025 test RMSE | 2026 transfer RMSE |
| --- | ---: | ---: |
| Context | 1.384803 | 1.353829 |
| Context + teams | 1.382101 | 1.355002 |
| Above + observed roles | 1.346707 | 1.325424 |
| Above + actor identity | 1.346298 | 1.324947 |

Units are EP per play. Actor identity improves on the role model by only
0.000410 EP/play in the historical test; its paired 95% game-bootstrap difference
interval is [-0.000925, +0.000056], spanning zero. The 2026 difference is
-0.000477 [-0.000786, -0.000155], a small improvement. These are outcome-error
intervals, not uncertainty in player value. Game resampling does not fully capture
cross-game team dependence, and one historical season is insufficient validation.

The transfer joint model's team-game mean-EPA RMSE is 0.201752 versus 0.187204
for context-only, so improvement in play error is not uniform improvement in team
outcomes. Most gain over team-only comes from realized role information. Neither
result validates the allocation to individuals or authorizes leaderboard admission.

The fitted joint design has 914 columns, including 830 actor-role columns. Three
actor-column groups are identical. Across penalties 10/100/1000, an actor
coefficient changes by as much as 0.775 EP; this is not a cumulative CAVAA value.
Unseen actor appearances are recorded explicitly in both held-out cohorts. Their
prediction uses the shrinkage origin, not an asserted zero football contribution.
All 32,813 historical and 11,441 transfer observations are retained, including
87 and 27 ambiguous-actor plays respectively.

## Engineering decisions and verification

Used pinned optional NumPy 2.2.6 and SciPy 1.15.3, both permissive BSD packages,
inside this repository's existing environment. Sparse LSQR handles separate
component penalties with an unpenalized intercept. The ingestion/contracts layer
remains standard-library Python. No additional server or paid resource is required.

Immutable JSON objects preserve the fitted state, per-play component predictions,
metrics, source IDs, committed code, plan and runtime. No executable pickle is
needed. Source/derived hashes are verified before fitting. Numerical replay checks
structure exactly and floats within recorded tolerances; cross-platform byte
identity is not promised. The actual build and replay each took about 11 seconds
on this machine with network construction and socket connections blocked.

152 offline tests pass, including 23 new modeling tests. They cover a dense
reference solution, known-effect recovery, perfect coappearance, role-only
ablation, unseen actors, preserved negative/ambiguous outcomes, missingness,
chronological splits, test-outcome leakage, stronger-penalty tie-breaking,
solver nonconvergence, paired bootstrap, accounting, corruption and replay.
Compilation and whitespace checks pass. Remote Python 3.11–3.13 CI is recorded
on the PR. Maximum real outcome-accounting error is below 2e-15 EP.

Self-review caught a synthetic fixture that accidentally aliased QB identity with
down; corrected the fixture to cross context with actor pairs, while retaining an
explicit confounding test. Review also added the observed-role ablation before
any real fit, avoiding an identity claim based only on role presence. Reviewed the
full diff, no-test-outcome selection, joint accounting, source provenance, dependency
licenses, model labels and documented incomplete qualification/benchmark gates.
