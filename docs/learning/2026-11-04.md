Previously, the static ZIP preserved an inspectable website but not the bytes
needed to regenerate its observations. [Explorer recovery](../RECOVERY.md) now
records exactly the content-addressed files read by successful raw-source,
ledger and Explorer replay. It packages those bytes with their archived licenses,
credits, the original site ZIP and a hashed recovery inventory. Unrelated local
files and historical/model research datasets are excluded.

Restoration checks the independently trusted archive hash, validates a strict
bounded inventory, writes a private sibling staging directory, then replays using
only the restored stores. Only a complete successful result is renamed into the
new destination. Existing destinations, even empty ones, are refused; failed
operations remove only their own staging. The original manifest bytes are retained.
No production pointer changes and no original source store is rewritten.

## Decisions and statistical concepts

- **A digest is an identity, not a backup.** Lost source bytes cannot be recovered
  from a SHA-256 string. The recovery artifact retains the actual bytes; an
  independent trusted digest detects changed downloads. It does not authenticate
  itself or guarantee a remote host will never delete it.
- **Replay is stronger than extraction.** A valid ZIP with internally consistent
  hashes could still omit a ledger or contain an unrelated object. The existing
  semantic replay recomputes observations, then the recorder verifies that the
  retained file set is exactly what that computation consumed.
- **Reproducibility is not player attribution.** Reproducing 425 observed sack
  credits does not prove how many expected points a defender personally created.
  All 17 CAVAA modules remain unadmitted; numeric CAVAA cannot appear in this
  archived review. Benchmark and eligibility policies are unchanged.
- **Recovery does not advance time.** The November operation preserves the
  October 22 cutoff, Week 6 games and retrospective chart labels. It cannot be
  described as current 2026 coverage or a historically available weekly ranking.
- **License scope follows the inputs.** Version 1 permits only this reviewed
  2026 CC-BY-4.0 source family and preserves attribution/license text. Historical
  participation and its distinct terms need separate review and retention.

The implementation uses the stdlib and existing source/review validators. It
introduces no dependency, paid infrastructure or recurring charge. The 128 MiB /
128-member local format bound is explicit, and fixed uncompressed ZIP metadata
makes repeated artifacts byte-identical for the same producer revision and inputs.
The current source stores and compiled site fit in a 32.54 MB archive. Python
matrix CI, unittest, Ruff, coverage diagnostics, React/TypeScript, browser tests
and read-only workflow permissions are unchanged.
