## What changed and why

The previous elliptical sampling proposal underrepresented weak team/game
variance tails. The new proposal uses one-dimensional conditional density tables
plus a proper Gaussian prior component for full support. Exact joint weights
preserve interactions among variance parameters. This changes where calculations
are concentrated; it does not choose a more favorable prior or player score.

Independent adaptive integration checks the resulting means and interval-endpoint
probabilities. Known-answer tests caught interpolation corners and relative-error
scaling problems before NFL results. A smooth Student-t coordinate transform and
exact mass-offset identities fixed those analytic controls without changing gates.
The actual NFL pilot then exposed a different limitation: repeated rule solves
and expensive splitting along every integration dimension.

The frozen plan explicitly permits exact reuse. A bounded cache removes identical
calculations; equivalence tests compare complete cached/uncached results, including
deliberate failures. A solve-budget-aware subdivision ceiling retains the last
complete error estimate rather than losing diagnostics to an interrupted region.
It cannot certify a nonconverged reference. Original failures stay archived.

## Results and statistical concepts

The original real QB, team control and three consumed stress cases all pass the
unchanged QMC checks. Both QB prior sensitivities pass too. Every original
independent reference exhausts 90,000 target solves. The cached follow-up provides
complete real-model error estimates and still rejects both candidates. All five

rebuild is byte-identical, and its model/result bytes equal the original version.
All decisions, timings and artifact IDs are in the [results](../VARIANCE_REFERENCE_RESULTS.md)
and [audit](../audits/2026-11-10-variance-reference.json).

For the primary QB, raw reference differences are 0.00778 posterior SD and 0.000837
CDF probability. Those alone look small, but the reference's own estimated error
is too large. Dropping that error or accepting a nonconverged status would create
false confidence. Propagation includes numerator and normalization uncertainty;
these estimated
errors are not rigorous bounds or measured errors against NFL truth.

A **proposal** determines numerical sampling locations; the **posterior** is the
distribution defined by the observations and scientific model. Correct weights
let us improve the former while keeping the latter unchanged. An **independent
reference** tests integration accuracy. **Calibration** asks whether uncertainty
intervals cover known simulated truths appropriately. **Attribution** concerns
which player/team contribution the observational assumptions support. These are
different claims, and a passing software suite proves none of them by itself.

Maximum per-play reconstruction error is 8.88e-16 EP; 38 negative player estimates
remain. Shared outcome accounting avoids duplicated credit. Allocating a season
effect across a player's opportunities is not an observed game-by-game performance
rating. Historical plays inform estimation without adding 2026 points.

The three synthetic draws were already consumed, so this pilot supplies no fresh
coverage evidence. The earlier 192-fit calibration remains unfinished. Week 10
stays sealed. No interval was inflated and no accuracy/admission gate was relaxed.
