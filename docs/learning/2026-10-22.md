## Statistical concepts

An identifier is not necessarily time order. Two 2025 games had an end-game marker
followed by a higher-ID record describing an earlier timeout or kneel. The old
completion rule excluded them. V2 uses quarter/clock evidence alongside the explicit
end marker and matching final scores. It still rejects missing markers, later
events, ambiguous equal-clock events and missing timed-event clocks. Overtime can
end before its clock reaches zero. The rule remains cross-file evidence, not an
independent NFL final-status feed or an exact final-whistle timestamp.

Opportunity counts need set unions. A scramble is both a dropback and a rush but
is only one combined QB opportunity. Similarly, one player appearing in multiple
actor fields on the same play must not receive duplicate unique-play counts.
The ledger stores the team EPA outcome once; passer and target links do not each
receive that full EPA. Future joint models must retain shared/unallocated components
and explicitly reconcile their contributions with the modeled outcome.

Missing actors cannot justify removing bad team outcomes. The 27 current-season
aborted plays keep their observed EPA/context while their actor links await review.
A missing receiving target can mean a throwaway or unavailable identity; it is not
zero receiver value. Even a valid passer link does not establish that player's
roster position: a receiver can throw a trick pass. Actor, positional benchmark
and leaderboard qualification populations remain different concepts.

## Engineering decisions

Preserved the legacy completion implementation as an explicit policy. New pregame
and defensive reports use version 2; replay chooses the recorded version. This
allows a correction without silently changing previously published evidence.
For the historical comparison, held both raw receipts and cutoff fixed so only
the completion interpretation changes.

Reused the content-addressed store and extracted the existing preplay parser into
a shared module without changing its output. No runtime dependency was added.
Offensive objects carry source receipts, source license/attribution, code revision,
cutoff and policy. Build/replay are offline; live capture is a separate explicit
step. Observed and context/outcome-complete workloads are separate, and unresolved
positions, stints and qualification denominators remain false in the output.

  87 aborted plays and 749 passes without a recorded target. No cross-team actor
  identity conflicts were found in either audited ledger.
