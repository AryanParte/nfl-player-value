## Statistical concepts

**Prediction and allocation ask different questions.** Two defenders can each
play half a game, one on excellent plays and one on poor plays. Their game-level
fractions are identical. The synthetic rotation test recovers their opposite
known effects from lineups; aggregation erases the contrast completely. Ridge
still returns a unique answer, but its penalty supplies the missing separation.

The real final design has 951 defender columns. After subtracting context/team
information, play-level data support 922 independent linear directions at the
fixed numerical tolerance; aggregates support only 301. That leaves 29 versus
650 unidentified dimensions before regularization. Higher rank is necessary for
separating linear effects, not proof of causal or correct player attribution.
Both views have six groups of identical defender columns.

**An average outcome changes the fitting problem.** The rich fit minimizes summed
play errors; the degraded fit minimizes team-game mean errors weighted by included
plays. Both use linear context transforms so averaging does not secretly change
the feature definition. Aggregation removes within-game covariance between
outcomes, context and lineups. Its lower game-level prediction error cannot be
interpreted as proof that individual information was preserved. Realized average
score states also reflect earlier plays; neither model is a pregame forecast or
an approved way to remove player-created context from CAVAA.

**Shrinking toward zero does not define an average NFL player.** Both views select
penalty 1000, the strongest in the predeclared grid. This bounded choice is not a
claim of a global optimum. It does not replace the first-unit positional benchmark.
Equal-player/opportunity-weighted sensitivities, leaderboard qualification and
cumulative CAVAA are not computed here. No participant is removed for having too
few snaps to qualify for a future leaderboard.

## Engineering decisions, verification and self-review

Reused the existing pinned optional NumPy/SciPy and sparse LSQR. No extra service,
package or infrastructure was needed. The degraded fitter accepts a strict
aggregate schema and rejects per-play IDs/lineups. Both views must reconstruct the
same complete-game cohort, signed EPA, context means and defender appearance
counts before fitting. Weights preserve the intended sum-of-errors penalty units.
Shared context/team terms and residuals remain unallocated; full team EPA is never
credited independently to all 11 players.

171 offline tests pass, including 19 new defensive tests. Tests cover a dense
weighted-ridge reference with unequal game sizes, a known-effect rotation and
permutation, collinearity/rank loss, linear aggregation, chronology, corruption,
source/target mismatches, unknown defenders, convergence failure, paired bootstrap,
accounting, and test-outcome perturbations that cannot change model selection.
Compilation and whitespace checks pass. Real build and replay each succeeded with
HTTP opener construction and socket connection calls patched to fail. Remote
Python 3.11–3.13 CI is reported on the PR once complete.

Self-review fixed a completeness edge case: an additional candidate with missing
context/outcome inside a retained game must fail rather than disappear. It also
made the rank tolerance relative to the original defender Gram scale, preventing
numerical noise in a fully projected-away block from masquerading as identified
information. Rechecked the full code diff, positive defense sign, penalty units,
held-out selection, negative outcomes, and derivative license boundaries.

Model states and predictions are non-executable JSON. Each independent object
retains the exact source IDs, plan, code/runtime and FTN Data via nflverse
CC-BY-SA-4.0 attribution/derivative terms. The public audit retains the same terms;
MIT applies to software, not a relicensing of data. Raw and generated objects
remain local content-addressed artifacts outside Git; durable remote retention is
still a release prerequisite. Numerical replay checks structure exactly and floats
at absolute 1e-9 / relative 1e-8. Selected-fit row-accounting error is below 1e-15 EP.
