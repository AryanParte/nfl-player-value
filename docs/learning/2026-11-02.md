## Statistical concepts

**Participation, observation and admission answer different questions.** A player
with three games and enough opportunities may inform the model and meet the
participation policy, yet still lack a defensible individual-value estimate. Low
participation does not remove useful modeling information or benchmark members.
The adapter preserves the existing threshold grid and opportunity counts while
keeping current main-leaderboard qualification false.

**A passing calculation is not a passing model.** Offensive and defensive
component arithmetic passed the bounded reconstruction tests. That says the
pieces sum correctly, not that value has been uniquely attributed to players.
The contract prevents using an accounting finding to stand in for uncertainty.
Failed, insufficient and untested gates remain distinct; an unimplemented long
snapper model is not a numerical zero, and a failed defender-prediction criterion
does not mean defenders contribute no value.

The research findings are unchanged: sparse observed transitions, selected
denominators and strong shrinkage dependence do not resolve attribution. Primary
intervals fail the stronger-signal simulations despite near-nominal coverage
under the model's own prior. These are simulation failures, not measured actual
NFL player errors. Targeted receiving is partial and cannot be relabeled as full
receiver value. No first-unit benchmark, sensitivity definition, penalty,
cumulative accounting rule or eligibility threshold was changed to gain admission.

## Architectural decisions and verification

The implementation uses Python's standard library and the existing eligibility
API. Frozen dataclasses and tuples keep loaded decisions separate from mutable
display summaries. Strict JSON rejects duplicate fields, nonfinite constants,
unknown/omitted modules, incomplete gates, mismatched roles/scopes/model plans,
changed policies, unknown evidence and path escapes. Registry input reading is
bounded before parsing. An expected registry digest prevents a caller from
silently substituting a different decision.

Version 1 intentionally has no positive-admission path. New evidence must lead to
a reviewed contract and registry revision, not a flipped flag or an experimental
label. This keeps the implementation small while the actual ranking schema and
publisher are unfinished. A clean `check` command means the non-admission record
is valid; it does not authorize a release. The command writes no pointer or
artifact and performs no network activity. Existing Explorer snapshots and replay
formats remain intact.
