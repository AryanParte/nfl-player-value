# October 19, 2026 — real snapshots and offline replay

## Built and why it matters

Confirmed the owner merged PR #1 and CI passed, then started
`codex/versioned-source-ingestion` from current main. Implemented public nflverse
PBP, season-roster and depth-chart capture, immutable local storage, exact source
provenance, quality/coverage audits and offline replay. See [the ingestion guide](../INGESTION.md)
and [machine-readable audit](../audits/2026-10-19-sources.json).

A URL is not a version: an existing season file can receive corrections. SHA-256
identifies exact bytes. Capture resolves the published asset hash before download
and rejects a mismatch, preventing a source changing mid-run from silently mixing
versions. Revised bytes create a new receipt while old snapshots remain available.
Compressed and decoded hashes identify the download and CSV content respectively;
neither proves the football observations or player attribution are correct.

## Engineering decisions

A thin standard-library CSV/gzip layer preserves raw bytes before dataframe
transformations. It reuses nflverse EPA and does not rebuild that model. It needs
no new runtime dependencies. Atomic non-overwriting publication prevents partial
files from looking complete; the receipt is published last. Replay verifies all
saved objects and regenerates their audit without fetching newer data.

An end-game marker is evidence, not an independently verified completion timestamp.
A missing ID is not a zero contribution. Raw preservation is separate from model
admission: unresolved rows remain in the archive and are flagged. All source audits
explicitly report `ranking_ready=false`; no player scores were generated.
