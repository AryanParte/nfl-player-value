## Concepts and decisions

- A portable artifact needs every dependency actually read during reconstruction,
  including previous snapshots used for comparison. A list of hashes cannot
  recover lost bytes. Recording reads avoids indiscriminate directory backups.
- A recent candidate can become unsuitable before packaging if another game starts
  or a source ages beyond policy. The CLI rechecks the actual packaging-attempt
  time, with no historical override. Publication will need its own current check.
- Reproducibility is time-specific. A restored check is evidence about its original
  time; it does not grant permission to publish now. The packaging check does not
  change the candidate's game cutoff.
- Isolated builds reduce local side effects. They are not a security sandbox for
  untrusted compiler plugins and do not implement hosted atomic publication.
- Reliable packaging does not validate player attribution. First-unit CAVAA,
  equal-player/opportunity-weighted sensitivities, eligibility separation and all
  admission decisions remain unchanged.
