## Implementation and architectural decisions

The design commit `e586379` precedes the numerical implementation `ac85ca6` and
fresh draws. One bounded multi-start search receives only a callable log density
and original proposal geometry. It tries 24 starts from a broader search cloud,
retains every optimizer attempt, constructs local curvature components and fits
component masses with independent points. A fixed defensive component retains
full support; complete mixture weights preserve the original target. It neither
clips negative CAVAA values nor changes football priors, likelihood or benchmarks.

The study reuses existing NumPy/SciPy, QMC, confidence calculations, zero-mean
controls and immutable storage. Search, finite differences, Hessians, pilot,
control fitting, coarse evaluations and both paired correction evaluations are
counted. Candidate trials consume 76,577–77,641 evaluations against 90,000. No
sample enlargement or favorable retry occurs. The preflight schema cannot be
accepted by the archived NFL certificate loader, even if a small screen passes.

The true-component oracle is deliberately segregated: it uses synthetic knowledge
unavailable to NFL inference and is never a deployable alternative. It can help
explain a failure without making practical discovery or uncertainty claims.

## What the results teach

A mixture component and a density mode are different. A small broad component can
produce important tail probability without forming another peak. Case 3 finds one
mode in every trial, with all 24 optimizer starts reporting usable convergence.
Its mean and endpoint precision still fail in all 32 trials. A post-result
analytical calculation, declared separately at `635b9ea`, confirms one mode in
the unperturbed fine-target mixture. The calculation is verified using independent
Gaussian derivative formulas and a stronger-component control with two peaks.
It is not an exact theorem about the sine-tilted coarse target or a new experiment.

Case 7 fails through discovery: 22 trials find both modes and all pass precision;
ten find one and none pass. Those conditional counts are explanatory and cannot
be used to discard unsuccessful trials. All 32 point estimates, including the
failed confidence trial, remain in the error analysis. The second standardized
mean's RMSE is .122 SD. Local convergence alone provides no global coverage proof.

Even correct synthetic components do not guarantee the required endpoint
precision on a finite draw. The oracle clears three screens but achieves only
87.5% precision on case 6, missing four endpoint checks. Its small-sample result
is not a population failure-rate estimate or an argument for changing intervals.
No oracle or paired plain result is selected after inspecting these outcomes.

Eight passing screens are useful feasibility evidence, not full certification.
These 32-trial checks intentionally stop a poor candidate before an expensive
coverage campaign. They do not replace the full coverage lower-bound gate,
validate the football model or remove teammate/team confounding. All original
numerical tolerances and player-admission requirements remain intact.
