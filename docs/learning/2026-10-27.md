## Statistical ideas and architectural decisions

In the additive model, substituting the benchmark while retaining a player's
context cancels shared team/situation terms in the contrast; those terms still
participate in the joint fit. An illustrative 0.1-point difference over 50 modeled
opportunities yields 5 expected points above that benchmark. This measures the
declared opportunity-conditioned component, not all value generated by choosing,
earning or avoiding an opportunity. In particular, the baseline's observed-role
terms can absorb QB-created value, and target-only receiving excludes blocking,
decoy routes and target earning. Arithmetic agreement cannot resolve these gaps.

**Covariance matters.** A player can be part of his own benchmark, and teammate
effects can move together. We calculate the variance of the entire difference
using the joint covariance matrix; independently adding player and benchmark
variances would be wrong. The covariance is conditional on an iid Gaussian
working model, a fixed penalty and a plug-in residual scale. It is not calibrated
NFL uncertainty or a causal/rank interval. Exactly zero residual scale is rejected.
Unobserved benchmark components receive explicit prior parameters and uncertainty
rather than falsely certain zero predictions. The audit records their weight.

The existing pinned NumPy/SciPy stack supplies Cholesky solves. Independent tests
compare means/covariance against dense inverse calculations and the existing LSQR
baseline. Legacy model/replay code remains unchanged. Existing immutable JSON
storage and numerical replay are reused; full covariance stays in memory and is
recomputed. No new package, database, secret, hosting service or CI system is added.

**Qualification is a different population.** All measured actors remain in the
fit. First-unit candidates remain benchmark members even with zero opportunities;
the equal-player sensitivity uses positive exposure, and opportunity weights use
its measured amount. Thresholds cannot change those populations. The narrow
exposure rule only proves a denominator when one consistent team/role has positive
offensive participation in every completed team game in the window. Gaps, trades,
possible missed games and late entry remain unresolved; roster status never fills
them. Zero targets in a game with an observed carry is still observed participation.
