## Decisions and statistical concepts

- **Integrity is not validity.** SHA-256 establishes which bytes were reviewed.
  A matching hash does not prove correct player attribution, calibrated intervals
  or freshness. The package always records `ranking_ready=false`.
- **Missing is not zero.** A cornerback with no defensible individual estimate
  has unknown CAVAA, not an average or zero-value season. The Explorer's recorded
  sacks/interceptions remain event counts, separate from modeled player value.
- **Qualification is not admission.** Passing a three-game/opportunity threshold
  does not establish that the model isolates player contribution. Benchmark
  membership stays independent of both leaderboard participation and admission.
- **Dates answer different questions.** Reviewing a model in November does not
  add games to an October archive. No recency weighting or retrospective coverage
  relabeling was introduced.
- **Determinism needs a whole chain.** The bundle records committed producer code,
  source/report identities, npm lock, runtime versions and every public file hash.
  ZIP ordering/timestamps/permissions are fixed. Raw inputs must still be retained;
  a hash cannot reconstruct lost data.

The browser receives the pinned raw registry instead of a second derived decision
format. Python verifies bound sources; Zod verifies the browser's contract after
the byte hash. The existing React/TypeScript/Vite stack, Python unittest suite,
matrix CI and read-only workflow permissions are unchanged. No new dependency,
hosting service, purchase or recurring cost was introduced. The Sites skill's
local validation guidance was used within this repository; no new Site repository
or hosting product was created.
