reference for the **repaired** conditional target? The last full QB reference

conditional repair did not answer this question. Its original-residual arithmetic

`I_r = Q_r(coarse) + R_r(fine - coarse)`.

Q and R use independent scrambled Sobol nets; fine and coarse in R use the same
points and proposal density. Both apply the exact proposal-mixture masses.
Linearity gives E[I_r] = integral(fine). This identity is about **unnormalized**
mass and numerator integrals; never subtract separately normalized estimates.
Fieller ratios from the combined replicate vectors retain mass/numerator
covariance. Sample variation includes both levels. Student/Fieller numerical
sets remain approximate, not universal bounds or player uncertainty intervals.

Fine is `exact_alias_residual`; coarse is the same exact-alias QR system without
the original-row residual correction. The latter is a control variate, not the
target or a certified substitute. Its known near-alias failure remains visible.
No precision clipping, jitter, tail truncation, zero-likelihood replacement or
posterior change is permitted. Either level's exception fails the case.
